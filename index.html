1. 시작하기 전에 확인할 것

클로드 데스크탑 안에는 '채팅 및 Cowork'와 'Code' 두 가지 메뉴가 있어요.

이 중 'Code' 메뉴(클로드 코드)는 유료 요금제(Pro 이상)를 사용해야 켜져요. 무료 요금제라면 Code 메뉴가 보이지 않거나 눌리지 않을 수 있으니, 먼저 회사에서 안내받은 계정이 유료 요금제인지 확인해 주세요.

2. 설치하기

1단계(Git 준비)만 윈도우/맥에 따라 다르고, 나머지 단계는 똑같아요. 내 컴퓨터에 맞는 1단계만 따라 하신 다음 이어서 진행하세요.

2-1. 1단계 · 깃(Git) 준비하기

윈도우(Windows)

깃(Git)은 클로드 코드가 작업 내용을 안전하게 저장하고 관리하는 데 필요한 프로그램이에요. 클로드 데스크탑을 쓰려면 먼저 설치해야 해요.

  1. 아래 주소로 들어가서 깃(Git) 설치 파일을 내려받으세요.
    https://git-scm.com/downloads/win
  2. 대부분의 컴퓨터는 '64-bit Git for Windows Setup'(X64 버전)을 받으면 돼요.
  3. 다운로드된 파일을 더블클릭해서 실행하세요.
  4. 설치 화면이 여러 번 나오는데, 특별히 바꿀 것 없이 계속 'Next(다음)' 버튼만 눌러서 끝까지 진행하시면 됩니다.
맥(Mac)

맥 컴퓨터에는 대부분 깃(Git)이 이미 설치되어 있어서 따로 설치하지 않아도 되는 경우가 많아요. 혹시 실행 중 깃이 없다는 안내가 나오면, 화면에 뜨는 설치 안내를 그대로 따라 설치해 주시면 돼요.

2-2. 2단계 · 클로드 데스크탑 설치하기

  1. 클로드 데스크탑 다운로드 주소(https://claude.com/ko/download)로 들어가세요.
  2. 내 컴퓨터에 맞는 설치 파일(윈도우용 또는 맥용)을 내려받아 실행하세요.
  3. 화면에 나오는 안내에 따라 설치를 끝까지 진행하세요. (맥은 응용 프로그램 폴더로 옮기면 완료돼요.)

2-3. 3단계 · 로그인하기

  1. 설치가 끝나면 클로드 데스크탑을 실행하세요. 아래와 같은 시작 화면이 나오면 '시작하기' 버튼을 누르세요.
  2. 안내에 따라 로그인하면 바로 사용할 준비가 끝나요!

3. 첫 화면 둘러보기

로그인을 하면 왼쪽 위에 두 개의 메뉴가 보여요.

  • 채팅 및 Cowork — 클로드와 대화를 나누거나, 함께 문서·자료를 만드는 곳이에요. 입력창 근처의 '채팅' / 'Cowork' 버튼으로 둘을 전환할 수 있어요.
  • Code — 클로드가 직접 프로그램(코드)을 만들거나 수정해주는 곳이에요. 이 매뉴얼에서는 이 'Code' 메뉴를 사용하는 방법을 배울 거예요.

4. 클로드 코드 기초 사용법

4-1. 새 세션 시작하기

  1. 'Code' 메뉴로 들어가면 왼쪽 위에 '+ 새로 생성' 버튼이 보여요. 이 버튼을 누르면 새로운 작업을 시작할 수 있어요.
  2. 클로드 코드가 작업할 작업 폴더를 골라야 해요. 최근에 쓴 폴더가 있다면 목록에서 고르고, 없다면 '폴더 열기...'를 선택하세요.
  3. 폴더 선택 창이 뜨면, 작업할 폴더를 새로 만들거나 기존 폴더를 선택한 뒤 '폴더 선택' 버튼을 누르세요. 폴더 이름은 띄어쓰기 없는 영어로 만드는 게 좋아요. (예: MyWorkFolder)
  4. 처음 사용하는 폴더라면 "이 워크스페이스를 신뢰하시겠습니까?" 창이 떠요. 클로드 코드가 이 폴더의 파일을 읽고 쓸 수 있도록 허락하는 절차예요. 내가 고른 폴더가 맞다면 '작업 공간 신뢰'를 누르세요.
  5. 이제 어떤 작업을 할지 적는 화면과, 사용할 모델(클로드의 종류)을 고르는 화면이 나와요. 처음이라면 기본값을 그대로 두어도 괜찮아요.
  6. 모델은 클로드의 종류예요. 일상적인 작업은 'Sonnet 5'면 충분해요. 기본값 그대로 두고 시작해도 괜찮아요.
  7. 노력은 '더 빠르게'와 '더 스마트하게' 사이에서 정하는 설정이에요. 어렵게 생각하지 말고 기본값 그대로 두어도 돼요.

4-2. 작업 권한 모드 이해하기

화면 아래쪽 '자동' 버튼을 누르면, 클로드가 작업할 때 얼마나 자유롭게 움직일지 아래처럼 고를 수 있어요.

자동 (기본, 권장)클로드가 알아서 권한을 판단해서 처리해요. 처음 사용하시는 분들은 이 모드를 그대로 사용하세요.

그 밖에 수동(변경하기 전에 항상 확인), 편집 자동 수락(모든 파일 편집을 자동으로 승인), 계획(변경하기 전에 계획부터 만들기) 모드도 있어요. 필요할 때 바꿔서 써보세요.

권한 무시목록 맨 아래 '권한 무시'를 켜면 모든 확인을 건너뛰고 클로드가 바로바로 작업을 진행해요. 편리하지만 실수로 원치 않는 변경이 생길 수 있어 초보자에게는 추천하지 않아요.

4-3. 첫 작업 요청해보기

이제 실제로 클로드에게 일을 시켜볼 차례예요. 화면 아래 입력창에 하고 싶은 작업을 문장으로 적으면 돼요. 어렵게 생각하지 말고, 사람에게 부탁하듯이 적으면 돼요. 짧게 한 문장으로 적어도 되고, 아래처럼 원하는 내용을 자세히 적어도 좋아요. (이 예시는 이 페이지 아래에서 직접 플레이할 수 있는 비행기 게임을 만들 때 실제로 사용한 요청이에요.)

예시 입력
  1. 장애물을 피하고 부수는 비행기 게임을 만들 것이다.
  2. 맨 하단에 내가 조종하는 비행기가 있으며, 미사일을 발사하여 장애물을 부술 수 있다. 또한 상단에서 하단으로 장애물이 떨어진다.
  3. 장애물의 종류는 매우작음, 작음, 중간, 큼, 매우큼 5단계의 크기로 구성한다.
  4. 장애물에 5번 피격당하면 게임 아웃이다.
  5. 스테이지마다 1분의 시간이 주어지고 1분동안 생존하면 다음 스테이지로 넘어간다.
  6. 스테이지를 넘어갈 때마다 장애물의 개수가 증가한다.
  7. 스테이지는 10 스테이지까지 존재한다.

입력 후 엔터를 누르면 클로드가 작업을 시작하고, 화면에 진행 상황이 나타나요.

작업이 끝나면 채팅 안에 결과물을 요약해서 보여주는 카드가 자동으로 나타나고, 오른쪽에는 미리보기(Preview) 화면도 바로 함께 떠요. 따로 '시작' 버튼을 누를 필요 없이 결과물이 어떻게 동작하는지 바로 볼 수 있어요.

마음에 안 드는 부분이 있으면, 미리보기에서 직접 그 부분을 콕 집어 수정 요청을 할 수 있어요.

  1. 미리보기 오른쪽 위의 '요소 선택' 버튼을 누르세요.
  2. 고치고 싶은 부분에 마우스를 올리면 어떤 요소인지 표시돼요. 그 부분을 클릭해서 선택하세요.
  3. 입력창에 선택한 요소가 태그로 붙어요. 어떻게 고치고 싶은지 적어서 요청하세요.
    예시 입력 "게임 오버라는 말은 너무 부정적인 거 같아. 다음에도 잘 할 수 있다고 응원해주는 문구로 바꿔줘."
  4. 요청한 대로 수정된 결과를 미리보기에서 바로 확인할 수 있어요.

4-4. 사용량 확인하기

화면 오른쪽 아래에 있는 동그라미 아이콘을 누르면 지금까지 얼마나 사용했는지 확인할 수 있어요.

  • 컨텍스트 윈도우 — 모델의 단기기억이에요. 지금 대화에서 얼마나 사용했는지 보여줘요.
  • 5시간 한도 — 5시간마다 리셋되는 세션 사용 제한이에요.
  • 주간 한도 — 7일 동안 사용할 수 있는 전체 사용량이에요.

'자세한 내역 보기'를 누르면 더 자세한 사용 기록도 볼 수 있어요.

5. 마무리

여기까지 따라 하셨다면 클로드 데스크탑 설치부터 클로드 코드로 첫 작업을 맡기는 것까지 모두 해보신 거예요. 수고 많으셨습니다.
